# Android Remote CLI 使用说明

这是一个基于 Node.js 开发的命令行工具，旨在简化通过无线网络连接 Android 设备并使用 `scrcpy` 进行远程控制的过程。该工具支持自动下载依赖、管理设备历史 IP、处理无线配对以及自动重连。

---

### ⚠️ 重要：安卓端准备工作

在运行此脚本之前，请确保您的 Android 设备已完成以下设置：

1. **开启开发者选项**：
   * 进入手机 `设置` -> `关于手机`。
   * 连续点击 `版本号` (Build Number) ，直到提示“您已处于开发者模式”。
2. **启用无线调试 (Wireless Debugging)**：
   * 进入 `设置` -> `系统` -> `开发者选项`。
   * 找到 **无线调试** 并打开它。
   * **注意**：请确保手机和电脑处于**同一个局域网 (Wi-Fi)** 下。
3. **获取配对信息（仅限首次连接）**：
   * 在“无线调试”设置页中，点击“使用配对码配对设备”。
   * 记录下显示的 **IP 地址和端口** 以及 **Wi-Fi 配对码**。

---

### 一、 环境要求

* **Node.js**: 请确保您的电脑已安装 Node.js (建议版本 v16+)。
* **网络连接**: 电脑需要访问 GitHub 以自动下载 `scrcpy` 核心组件（仅首次运行需要）。

### 二、 安装步骤

1. 将脚本代码保存为 `index.js`。
2. 在脚本所在目录下打开终端，安装必要的依赖库：
   ```bash
   npm install inquirer adm-zip axios
   ```

### 三、 快速上手

运行脚本：

```bash
node index.js
```

#### 1. 首次运行

* 脚本会检测您的系统中是否存在 `scrcpy` 环境变量。
* 如果没有检测到，脚本会自动从 GitHub 下载 `scrcpy v3.3.1` 压缩包，并解压到您的用户目录下的 `.android-remote-cli` 文件夹中。

#### 2. 主菜单功能

* **连接设备**: 快速选择之前连接过的 IP 地址。
* **手动输入新 IP**: 输入新设备的 IP 地址和端口（默认为 5555）。
* **删除记录**: 清理不再使用的设备 IP 历史。
* **退出软件**: 安全停止 ADB 服务并关闭程序。

#### 3. 连接与配对逻辑

* **直接连接**: 如果设备之前配对过且处于激活状态，脚本将直接启动镜像。
* **自动配对**: 如果连接失败，脚本会提示输入“配对端口”和“配对码”。
  * *提示：配对端口通常与连接端口不同，请在手机“无线调试 -> 使用配对码配对”界面查看。*
* **错误处理**:
  * 若提示 `10061` 错误：通常是手机端的“无线调试”开关被关闭了，或者端口发生了变动。
  * 若提示 `10060` 错误：通常是 IP 地址输入错误或设备与电脑不在同一 Wi-Fi 下。

### 四、 文件存放路径

* **程序目录**: `C:\Users\您的用户名\.android-remote-cli`
* **配置文件**: `config.json`（存储您的连接记录）
* **scrcpy 核心**: 自动下载的 `scrcpy` 也在该目录下，不会污染您的系统环境变量。

### 五、 常用快捷键 (在 scrcpy 窗口内)

* **Ctrl + f**: 切换全屏。
* **Ctrl + h**: 返回主页 (Home)。
* **Ctrl + b**: 返回键 (Back)。
* **鼠标右键**: 息屏状态下唤醒屏幕 / 返回键。
* **文件拖拽**: 直接将 APK 文件拖入窗口即可安装。

### 六、 打包为独立 EXE 文件

#### 1. 执行打包命令

在终端输入以下命令：

```bash
npm run build
```

#### 2. 完成

打包完成后，你会得到一个 `android-remote.exe` 文件。

* 你可以将这个文件发送给其他人使用。
* 第一次运行时，它仍然会在 `C:\Users\用户名\.android-remote-cli` 目录下自动下载并配置 `scrcpy` 环境。

---

### 💡 提示：

* **图标定制**: 如果你想给 exe 加上图标，可以替换app.ico。
* **隐藏终端窗口**: 脚本是基于 CLI 的，所以必须保留黑窗口（终端）进行交互，**不要**尝试使用 `--windows-hide` 彻底隐藏，否则 `inquirer` 的菜单将无法看到。

---

### 常见问题排查

* **Q: 为什么下载 `scrcpy` 进度条不动？**
  * A: 因为下载源在 GitHub，如果网络环境不佳，可能需要开启加速器或多尝试几次。
* **Q: 手机连接后显示“未授权”？**
  * A: 请查看手机屏幕，确认弹出的“允许调试”对话框。
* **Q: 想要自定义 `scrcpy` 参数（如码率、分辨率）？**
  * A: 目前脚本默认使用标准参数启动。如需自定义，可以修改代码中 `runScrcpy` 函数的 `spawn` 参数数组。
